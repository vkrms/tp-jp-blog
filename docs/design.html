TP JP 3.0 Design System

A design system for the Travelpayouts Japan landing page. It is calm, flat and trust-first, uses one brand blue for actions, and saves warm orange for "free" and support moments.

This page is the human-readable mirror of docs/design.md, which is the source of truth. Tokens also live in docs/design-tokens.json (DTCG) and docs/design-tokens.css. Regenerate them with node tools/build-design-tokens.mjs. Source: Figma tp-landing-jp · node 388:330.

Colors

The palette is a neutral slate ramp, with one brand blue for action and a warm orange for free and support moments. Signals are kept sparse.

Typography

There is one family, Noto Sans JP (400 / 500 / 700). Line height is 150% for headings, 180% for reading text, 160% for UI text and 130% for buttons. Big numerals put their unit at half size.

Layout

Spacing tokens run from 2 to 160. Desktop is 1440 with a 48 margin and a 1344 container. Mobile is 375 with a 16 margin and a 343 single column. Sections open with 112 top padding on desktop.

Do's and Don'ts

✓ Do

  • Use primary blue for exactly one primary action per view, and use orange only for free, support and hero warmth.
  • Put a 表示例 tag on every card or illustration that shows a money amount, and a ※ Note under any claim with conditions.
  • Keep ※ notes quiet: note style, muted color, one line where it fits.
  • Set key figures with numeral-* and the unit at half size: 15年
  • Express depth with tinted surfaces and 1px blue-tint borders, and keep the focus ring for keyboard focus.
  • Use the desktop/mobile token pair for every heading, lead and body text.

✗ Don't

  • Don't add drop shadows, gradients or glassmorphism, because the system is flat.
  • Don't introduce a second typeface or use weights other than 400, 500 and 700.
  • Don't use a text color lighter than muted #667085 for readable copy.
  • Don't invent new radii; use only 4 / 12 / 20 / 28 / full.
  • Don't use red for anything other than form errors, or green for anything other than reward amounts.
  • Don't add letter spacing to body or lead text.
